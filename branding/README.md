# NetherSX2 Thor Experiment Branding

The launcher mark is a compact `N2` monogram with a Thor-style bolt and cheat-toggle motif. It is designed to stay readable at Android launcher sizes while making this personal experiment fork visibly distinct from stock NetherSX2/AetherSX2 builds.

Regenerate assets with:

```powershell
python tools\generate_brand_assets.py
```

Generated APK resources are stored in `branding/android/res`, README assets are stored in `docs/assets`, and APK resources are applied by `decomp/ApplyBrandingPatch.ps1`.
