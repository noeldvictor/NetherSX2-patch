# NetherSX2 Cheat Helper Branding

The launcher mark is a compact `N2` monogram with a cheat toggle/check motif. It is designed to stay readable at Android launcher sizes while distinguishing this fork from stock NetherSX2/AetherSX2 builds.

Regenerate assets with:

```powershell
python tools\generate_brand_assets.py
```

Generated APK resources are stored in `branding/android/res` and applied by `decomp/ApplyBrandingPatch.ps1`.
